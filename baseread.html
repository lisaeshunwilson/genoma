The pipeline, in four steps

  1. Parse the uploaded VCF for a variant's position (or rsID).
  2. Query Ensembl VEP, which aggregates dbSNP, ClinVar, and gnomAD annotations for that exact variant.
  3. Fetch the gene's real exon structure and chromosome location from Ensembl.
  4. Ask an LLM to write a plain-language summary, constrained to only the facts retrieved above — it's told explicitly to say "not found" rather than invent anything.

Known limitations

  • Assumes the GRCh38 genome build; flags a warning if a file specifies otherwise.
  • Annotates one variant at a time (a picker appears for multi-variant files).
  • OMIM is not yet connected — it requires a registered API key.
  • The curated library below is illustrative/educational, not a diagnostic reference.
